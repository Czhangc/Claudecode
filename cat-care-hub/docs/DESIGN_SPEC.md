# DESIGN_SPEC — 视觉与交互规范

> 本文件定义"长什么样、怎么动、怎么交互"。功能和验收标准见 `PRD.md`。视觉方向的设计稿在 claude.ai 的画布"猫咪健康管家 · 视觉方向"中（首页、体况评分、喂食方案、急诊提示、风格板），本文件是它的文字版，Claude Code 以本文件为准。

## 1. 品牌方向：暖 · 软 · 可信

**可爱是语气，可信是底线。** 日常照顾猫是治愈的事，界面要温暖、柔软、有一只可爱的猫陪着；但每个数字和建议都要让人放心，所以版面要干净，来源要看得见。

### 参考提炼

| 参考 | 采用 | 不采用 |
|---|---|---|
| 学习类 App（蓝色线稿人物） | 大圆角色块卡片；黑色胶囊按钮；每个模块一种主题色；进度环；插画探出画面 | 冷色基调 |
| 划船租赁 App（颗粒平涂插画） | 带细颗粒质感的平涂插画；物体突破卡片边界 | 高饱和钴蓝 |
| 3D 角色学习 App（奶油底） | 奶油暖色底；柔和投影；胶囊形选项 | 3D 渲染角色（代码无法生成或做变形动画，可以日后用于营销图） |

在 `tailwind.config` 的 `theme.extend` 中定义，组件里**不得**写死颜色值、圆角或阴影。

- 等级、状态不能只靠颜色区分，必须同时有图标或文字

### 2.2 字体

| 用途 | 字体 | 字重 | 字号 |
|---|---|---|---|
| 数字、英文 | Nunito | 800–900 | 大数字 28–56px |
| 标题 | Noto Sans SC（思源黑体） | 900 | 22–30px |
| 正文 | Noto Sans SC | 500 | 15–16px，行高 1.6 |

字体栈：`'Nunito', 'Noto Sans SC', 'PingFang SC', sans-serif`。国内访问 Google Fonts 可能不稳定，字体文件**自托管**，中文字体做子集化。

### 2.3 形状、间距、阴影

| Token | 值 |
|---|---|
| 圆角 | 大卡片 32px；普通卡片 24–28px；按钮、标签全圆角（999px） |
| 间距 | 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32；页面左右边距 20px |
| 阴影 | `0 6px 18px rgba(120, 80, 40, 0.07)`（暖色、很淡） |
| 点击区域 | ≥ 44 × 44px；主按钮高 56px；急诊页按钮高 64px |

## 4. 插画

### 4.1 主角：咪宝

主角就是咪宝本猫，设定稿见画布中的"咪宝 · 角色设定"（坐姿全身、脸部特写、俯视、配色）。

**认得出是咪宝的特征**（每张插画都要保留）：
- 棕色鲭鱼纹虎斑：身体两侧是弧形横纹，背上有一条背中线
- 额头 M 字纹，脸颊各两道纹
- 绿色大眼睛，眼周一圈暖橘色
- 粉鼻头，鼻梁上一小块白
- 白围兜、白手套、白袜子
- 腹侧和腿上带一点暖橘色
- 圆脸、身体圆润、腿短

**配色**

| 部位 | 色值 |
|---|---|
| 毛色底 | `#A08A6A`（头部稍亮 `#A28C6C`，腿 `#9A8464`，耳朵和尾巴 `#8E7859`） |
| 亮部（脸颊、背脊高光） | `#C9B594` / `#C4B08F` |
| 暗部（体侧、头顶） | `#6F5C44` |
| 斑纹 | `#3B3027`，透明度 80–85% |
| 腹侧暖橘 | `#C98B52` |
| 眼周暖橘 | `#C78A4E` |
| 白色部位 | `#F8F4EC`（围兜阴影 `#CFC4B5`，趾缝 `#D8CFC1`） |
| 眼睛 | 径向渐变 `#D6E4A6` → `#A3BC72` → `#6E8C4C`；瞳孔 `#1E1813`；眼眶 `#2A211C` |
| 鼻头 | `#E9A5A5`，高光 `#F9D6D2` |
| 内耳 | `#E7B9AC`，耳毛 `#F6EEE3` |
| 腮红 | `#EFA7A3`，透明度 40% |
| 胡须 | 浅色背景上用 `#B8A98F`，深色或彩色背景上用 `#FFFBF5` |

**画法**
- **不描边**。体积靠同色系明暗：暗部、亮部都是模糊过的色块（高斯模糊 3–7），裁切在身体或头部轮廓内
- 唯一的深色线是眼眶（2.2px，在 240px 宽的画布上），让眼睛成为表情中心
- 白色区域边缘轻微模糊（1.1），像绒毛而不是硬边
- 毛发颗粒：轮廓内叠加 `feTurbulence`（`baseFrequency 1.1`），`multiply`，透明度约 16%
- 尾巴的环纹用描边虚线（`stroke-dasharray`）实现，尾尖深色
- 眼睛：大、圆，两颗高光（左上大、右下小），光源统一在左上
- 小装饰：四角星、爱心，用 `ink` 或 `#E86A7E`，点缀即可

### 4.2 质感与构图

- 彩色卡片叠加细颗粒：SVG `feTurbulence`（`baseFrequency 0.85`，`numOctaves 2`，去饱和），`mix-blend-mode: multiply`，透明度 12%
- 插画可以探出卡片边缘（例如首页猫咪坐在卡片右上角）
- 一屏最多一个主插画

### 4.3 制作分工

- 咪宝和简单插画：Claude Code 按本节规格写 SVG 组件，放在 `src/components/illustrations/`
- 复杂插画：cccc 提供 SVG 文件，放在 `src/assets/illustrations/`，Claude Code 只负责接入和动效
- 现有设定稿是代码绘制的 SVG。如果之后用插画工具或 AI 生图做出完成度更高的版本，矢量化后按 4.1 的特征和配色交付，替换同名组件即可
- 需要变形的插画（体况轮廓）必须是代码生成的路径，见 6.3

## 5. 情绪分区

| 分区 | 页面 | 允许 | 禁止 |
|---|---|---|---|
| **日常区（活泼）** | 首页、体型、饮食、互动、知识卡片 | 咪宝插画、模块色、颗粒质感、轻微回弹动效、俏皮的标题 | 让人误以为"没事"的轻松措辞出现在健康提示里 |
| **安静区（克制）** | 分诊、疼痛观察、急诊、所有就医提示 | `paper` 底、`ink` 文字、`alert` 色块、大按钮 | 咪宝插画、颗粒、回弹、循环动画、表情符号、卖萌措辞 |

判断规则：只要页面内容涉及"要不要去医院"，就属于安静区。日常区里出现的健康警示（例如减重过快）用安静区样式的提示块。

## 6. 各流程的交互模式

### 6.1 通用
- 一屏只问一个问题，选项用大卡片或胶囊按钮，点选即前进（可返回修改）
- 多步流程右上角显示进度环
- 结果页先给结论，再给解释，最后给来源

### 6.2 首页（Phase 0–1）
- 顶部：问候 + 猫的名字；右上"紧急情况"胶囊（红点 + 文字），一次点击进入急诊速查
- 主卡片（体型色）：本周体重记录条 + 一句进度结论；咪宝插画探出卡片右上角
- 今日喂食条：主粮克数 + 零食额度，点击进入喂食方案
- 2×2 模块卡片：体型 / 饮食 / 互动 / 健康
- 底部导航：首页 / 记录 / 知识 / 我的

### 6.3 体况评分（F1.3）

1. **三个问题**：每题顶部一段循环小动画演示动作（手沿肋骨轻摸、从正上方俯视、蹲下从侧面看），下方 3–5 个插图选项，点选即前进
2. **拖动对比**：
   - 大卡片中央显示俯视轮廓，滑杆 1–9，拖动时轮廓平滑变胖变瘦
   - 初始值 = 前三题估算的分数
   - 滑杆轨道上用 `ideal` 色标出 4–5 分区间，下方标"理想"
   - 当前分数用 Nunito 56px 显示，旁边是区间标签（偏瘦 / 理想 / 超重 / 肥胖）和一句描述，描述旁显示"待核对"直到内容核对完成
   - 下方链接"对照 WSAVA 官方体况评分图确认"（新窗口打开）
   - 主按钮"就是它了，记录 N 分"；次按钮"重新回答 3 个问题"
3. **轮廓生成**：身体是一条闭合的 Catmull-Rom 曲线，经过颈、肩、腰、臀、尾根 12 个点，按下表的半宽（单位：200px 宽画布）生成。头、耳朵、尾巴不变

   | 分数 | 肩 | 腰 | 臀 |
   |---|---|---|---|
   | 1 | 30 | 16 | 27 |
   | 2 | 31 | 19 | 28 |
   | 3 | 32 | 23 | 31 |
   | 4 | 34 | 27 | 34 |
   | 5 | 36 | 31 | 36 |
   | 6 | 38 | 36 | 39 |
   | 7 | 40 | 42 | 42 |
   | 8 | 43 | 49 | 45 |
   | 9 | 46 | 56 | 48 |

   这是示意图，不是测量标准；表格本身不需要来源，但界面要说明"以官方图表为准"
4. 滑杆是原生 `<input type="range">`，有文字 label，支持键盘

### 6.4 喂食方案（F1.4）
- 顶部饮食色大卡片：厨房秤 + 猫粮碗插画，秤的显示屏上是每日主粮克数（动态文本），一只猫从右侧探头
- 两张数字卡：每日总热量、零食额度（附零食罐小图）
- 目标提示块：减重时显示"开始之前，建议先请兽医检查，并确认目标体重"
- "看看怎么算的"默认收起，展开后逐步显示公式和来源标签
- 底部一行估算说明（个体差异 ±50%，2–4 周后调整）
- 主按钮"保存为当前方案"

### 6.5 体重记录（F1.2）
- 输入：大号数字输入框 + kg 单位，默认填上次体重，方便微调
- 趋势图：处于减重计划时，在图上画出每周 −0.5% 到 −2% 的安全"跑道"（`ideal` 色、低透明度），体重线在跑道内就是安全的
- 减得太快的提示用安静区样式

### 6.6 知识卡片（F1.5）
- `paper` 底卡片：标题、摘要、来源标签（可点）、核对状态、最后核对日期
- 模块色只用在卡片左上角的小圆点，保持阅读区干净

### 6.7 环境五大支柱自查（F2.1）
- 顶部五根"柱子"图标，答完一个支柱就填满一根
- 结果按支柱分组：做得好的（`ideal` 标记）和可以改进的（附来源）

### 6.8 行为图鉴（F2.2）
- 一只可以点的猫：点耳朵、尾巴、眼睛，分别在几种状态间切换，下方卡片同步显示含义、你可以怎么做、来源
- 这是最适合录屏做内容的页面，动效可以多一点，但每次切换 ≤ 320ms

### 6.9 症状分诊（F3.1，安静区）
- 一屏一个问题，"是 / 否"两个 64px 高的大按钮
- 红线问题全部在前；命中即跳转急诊页
- 结果页三个等级，每个等级都是"图标 + 文字 + 颜色"三重表达

### 6.10 疼痛面部观察（F3.2，安静区）
- 每个面部特征一屏：三张并排的中性线稿（0 / 1 / 2）+ "看不清"选项
- 不用咪宝插画，线稿不做可爱化处理

### 6.11 急诊页（F0.2 / F3.1，安静区）
- `paper` 底，右上关闭按钮
- 急症块：标题"请立即联系兽医"、原因、"不要在家等待观察"
- 两个 64px 行动按钮：拨打常去的医院（主按钮）、查找附近 24 小时急诊（次按钮）
- "给兽医看的摘要"：症状、开始时间、最近体重、饮食
- 底部：依据的来源、"本工具只做就医分诊，不能诊断疾病"
- 页面无插画、无动效

## 7. 动效

| 项目 | 规格 |
|---|---|
| 时长 | 240–320ms |
| 日常区缓动 | 轻微回弹 `cubic-bezier(0.34, 1.4, 0.64, 1)` |
| 安静区缓动 | `ease-out`，无回弹；不出现循环动画 |
| 可以动的 | 页面切换、卡片按下、体况轮廓变形、"看看怎么算的"展开、行为图鉴状态切换、体况问题的演示小动画 |
| 不动的 | 数字结果（直接显示，不做滚动计数）、警示内容 |
| 减少动态效果 | 遵守系统 `prefers-reduced-motion`：关闭所有过渡和循环，演示动画改为静态图 |

实现：优先用 CSS transition；确实需要编排动画时才引入动画库，并在 `DECISIONS.md` 记录理由。

## 8. 无障碍

- 文字对比度 ≥ 4.5:1；彩色卡片上的次要文字用 `ink-on-color`
- 装饰性插画 `aria-hidden="true"`；表达信息的插画（体况轮廓、厨房秤）有 `role="img"` 和描述当前状态的 `aria-label`
- 所有可点元素是真正的 `<button>` 或 `<a>`；图标按钮有 `aria-label`
- 展开类按钮有 `aria-expanded`

## 9. 文案语气

- 说人话，短句子，先给结论
- 日常区可以俏皮（"拖一拖，哪只最像咪宝？"），安静区直接、具体、不吓人也不弱化（"请立即联系兽医"）
- 用猫的名字代替"您的宠物"
- 不出现诊断口吻；措辞统一放在 `src/copy/zh.ts`
