# Social Gym

随时打开就能用的社交觉察训练工具。**纯静态、全离线、无任何网络请求、无 API。**
目的不是考核你，而是：捕捉被忽略的信号 → 觉察自己的 autopilot → 刻意设计回应，并向老手的回应学习。

## 使用
双击 `index.html` 即可（它是单文件，内联了全部脚本和样式，也可直接放到任意静态托管）。源码在 `src/`，改完运行 `node build.js` 重新生成 `index.html`。数据只存在本机浏览器的 localStorage；可在「设置」里导出/导入 JSON。

## 练习流程
1. **捕捉信号**：分幕看场景 → 先写下你注意到的 → 揭示标注 → 诚实标记“注意到/漏掉”（累积成盲区地图）
2. **抓住自动反应**：限时写下第一反应（不修改）→ 命名自动模式 → 记录感受与被触发的需求
3. **刻意设计**：“暂停键”四问 + 写两个不同意图的回应
4. **老手拆解**：2–3 个老手回应（话术 → 机制 → 为什么有效 → 边界风险 → 语气时机）+ 容易翻车的反例；可收藏机制到工具箱

另有：模式镜（常漏信号、autopilot 分布、第一反应速度）、工具箱（12 种回应机制）、日志（事前意图卡 / 事后复盘）、每日微实验。

## 内容与语言
18 个场景：化解尴尬 6、应对挑衅 6、权力与面子 2、亲密关系 2、大场合 2。
界面可切换中/英；场景标题、情境、老手话术有英文版，**分析性文字（信号标注、为什么有效等）目前只有中文**，缺英文时自动回退中文。

## 添加场景
在 `scenarios.js` 里按现有格式追加 `S({...})`。字段：`domain / topic / dims(1–3) / timeline[谁,内容,线索] / signals[{id,type,layer,beat,text}] / veteran[{say,mech[],why,limits,delivery}] / pitfalls`。`type / layer / mech` 必须是 `taxonomy.js` 里已有的键。

## 说明
老手回应是示范思路，不是万能话术；有效性取决于关系、语境和你的语气。工具是自我觉察的辅助，不是心理评估。
