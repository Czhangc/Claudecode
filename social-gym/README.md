# Social Gym

随时打开就能用的社交觉察训练工具。**默认纯静态、全离线。** 只有当你在设置里填了自己的 API key、并点击 AI 按钮时，才会联网。
目的不是考核你，而是：捕捉被忽略的信号 → 觉察自己的 autopilot → 刻意设计回应，并向老手的回应学习。

## 使用
双击 `index.html` 即可（它是单文件，内联了全部脚本和样式，也可直接放到任意静态托管）。源码在 `src/`，改完运行 `node build.js` 重新生成 `index.html`。数据只存在本机浏览器的 localStorage；可在「设置」里导出/导入 JSON。

## 手机安装（PWA）
1. **开启托管**：GitHub 仓库 → Settings → Pages → Source 选 `Deploy from a branch` → Branch `personal-tool`、目录 `/(root)` → Save。（公开仓库免费；私有仓库需付费计划，否则改用 Netlify / Cloudflare Pages 拖拽 `social-gym/` 文件夹。）
2. 约一两分钟后访问 `https://czhangc.github.io/claudecode/social-gym/`。
3. **iPhone**：用 Safari 打开 → 分享按钮 → 添加到主屏幕。**Android**：用 Chrome 打开 → 菜单 → 安装应用 / 添加到主屏幕。
4. 之后像 App 一样全屏打开，首次加载后断网也能用。数据存在该设备的浏览器里，换设备请用设置里的导出/导入。

更新版本：改动后运行 `node build.js` 重新生成 `index.html` 和 `sw.js`（缓存版本号自动更新），提交即可；已安装的手机在联网打开时会拿到新版。

## 练习流程
1. **捕捉信号**：分幕看场景 → 先写下你注意到的 → 揭示标注 → 诚实标记“注意到/漏掉”（累积成盲区地图）
2. **抓住自动反应**：限时写下第一反应（不修改）→ 命名自动模式 → 记录感受与被触发的需求
3. **刻意设计**：“暂停键”四问 + 写两个不同意图的回应
4. **老手拆解**：2–3 个老手回应（话术 → 机制 → 为什么有效 → 边界风险 → 语气时机）+ 容易翻车的反例；可收藏机制到工具箱

另有：模式镜（常漏信号、autopilot 分布、第一反应速度）、工具箱（12 种回应机制）、日志（事前意图卡 / 事后复盘）、每日微实验。

## AI 点评（可选）
没有评价就只是自说自话，所以练习第④步提供：
- **AI 点评我的回应**：基于你写的“注意到了什么 / 第一反应 / 暂停四问 / 设计版”，给镜子式点评（捕捉得好的、漏掉的信号、对第一反应的解读、设计版的优点与风险和改写、下次小实验），不打分。
- **对方可能怎么回**：AI 扮演场景中的对方，分别回应你的第一反应与设计版，体验差异。
- **复制点评提示词**：没有 key 时，把同样的提示词复制到任意 Claude 对话里使用。

设置里填入你自己的 Anthropic API key（默认模型 Claude Opus 5.5，可换 Sonnet 5.5）。请求由浏览器直接发往 `api.anthropic.com`；key 只存本机、不进导出文件。**仅限个人使用，不要把填了 key 的页面公开部署。** 若在某些沙箱预览里联网被拦截，会提示失败，改用本地打开或“复制提示词”即可。

## 内容与语言
18 个场景：化解尴尬 6、应对挑衅 6、权力与面子 2、亲密关系 2、大场合 2。
界面可切换中/英；场景标题、情境、老手话术有英文版，**分析性文字（信号标注、为什么有效等）目前只有中文**，缺英文时自动回退中文。

## 添加场景
在 `scenarios.js` 里按现有格式追加 `S({...})`。字段：`domain / topic / dims(1–3) / timeline[谁,内容,线索] / signals[{id,type,layer,beat,text}] / veteran[{say,mech[],why,limits,delivery}] / pitfalls`。`type / layer / mech` 必须是 `taxonomy.js` 里已有的键。

## 说明
老手回应是示范思路，不是万能话术；有效性取决于关系、语境和你的语气。工具是自我觉察的辅助，不是心理评估。
